# 审查 epoch

在 **Epochs** 窗口中，一次点击选择的是**整个 epoch**，不是单个通道或采样点。用窗口里的箭头翻页；再次点击已高亮的 epoch 可反选。

![第三个 epoch 被选中时的多通道波形](/figures/epochs.png)
<p class="caption"><strong>沿通道方向看阴影。</strong> 阴影覆盖相同时间段的所有通道。这里选择第 3 个 epoch 只为展示操作，不代表它确实是坏数据。</p>

## 练习一次可撤销的修改

| 打开时的选择 | 本次操作 | 重开后保留 |
| --- | --- | --- |
| 空 | 点 1、3、5，再 **Mark** | 1、3、5 |
| 1、3、5 | 点 2、4、6，再 **Mark** | 1、2、3、4、5、6 |
| 1 至 6 | 再点一次 3，**Mark** | 1、2、4、5、6 |
| 1、2、4、5、6 | **Clear → Cancel** | 1、2、4、5、6 |
| 1、2、4、5、6 | **Clear → Mark** | 空 |

**Mark** 确认当前完整选择，包括空选择。**Cancel** 丢弃本次编辑，保留打开前的状态。两者都不写文件。回到工作台看 **Bad epochs** 的数量；这些 epoch 在[保存](/zh/guide/save)时才真正被移除。
